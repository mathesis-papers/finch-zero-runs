# 零点串与四周期捕获

从 $0,1$ 开始。每次把较早的数平方，加到较新的数上，再只保留除以三的余数。接下来两项是 $1$ 和 $2$，再下一项是 $2+1^2=3$ 的余数 $0$。随后相邻两项又变成 $(0,1)$。既然起点的两项相同、规则也相同，往后的结果就会重复。这个小例子说明了两件事：如何用有限信息处理无限数列，以及什么样的图案足以保证后面一直重复。

Haobo Ma 和 Wenlin Zhang 的[论文第 3 版](https://doi.org/10.5281/zenodo.24408308)延伸了 Steven R. Finch 提出的两个问题。第一个结果说明，给出图案长度的上界，不等于找得到达到上界的图案。第二个结果区分了数列已经开始重复的时刻，以及我们能从足够长的图案确认它在重复的时刻。

## 需要记住多少项？

选一个滞后量 $k\ge2$。前 $k-1$ 项全是 $0$，第 $k$ 项是 $1$；以后按 $x_n=x_{n-1}+x_{n-k}^2\pmod3$ 计算。下标从 $1$ 开始。在模三运算中，$1$ 和 $2$ 的平方都等于 $1$，因此数列每一步要么原地不动，要么沿着 $0,1,2$ 的圆环前进一格。

**有 $g$ 个间隔的零点串**从 $r\ge k+1$ 开始，零恰好出现在 $r,r+4,\ldots,r+4g$；这些零之间没有别的零。它含有 $g+1$ 个零，也可以是更长零点串的一部分。例如，滞后量为二时，第 $5$ 至第 $9$ 项是 $0,1,1,2,0$：两个零，一个间隔。第 $1$ 至第 $5$ 项虽然长得一样，却不算，因为起点早于 $k+1$。

## 为什么达不到十五？

Finch 证明：滞后量模四余 $0$ 或 $1$ 时，间隔数至多为 $\lfloor(k-1)/4\rfloor$。当 $k=61$，这个上界是 $15$。上界只是限制，不保证数列里真的有那么长的零点串。

::: {#lag-61 .remark mathesis="collected:finch-zero-runs:3:s1" title="定理 1：滞后量为 61 时最多恰有十个间隔"}
当 $k=61$ 时，最多恰有十个间隔；所有十间隔零点串的起点恰为 $2780+8946m$，其中 $m$ 是非负整数。最小最终周期是 $8946$，令所有 $n>\mu$ 满足 $x_{n+8946}=x_n$ 的最小 $\mu$ 是 $739$。
:::

算下一项只需要这一窗口中最早和最新的两项，但想继续算下去，就要保留整个 $61$ 项窗口。把它写成一个三进制数 $S_j$，最新一项在最右边；$S_0=1$ 对应止于第 $61$ 项的窗口。每次删掉最左边的一位，把其余各位左移一格，再在右边添入新值。只有整个窗口重现，而不是其中某一项重现，才足以保证往后重复。

论文的有限证书核对了 $S_0$ 到 $S_{9684}$ 两两不同，并核对下一个状态恰为 $S_{739}$。于是以后永远循环于这 $8946$ 个窗口。不同状态不能提前重合，所以得到的是最小周期和最小前周期。数列各项一旦周期重复，对应的整个窗口也会重复；反过来，每个窗口最早的一位就足以把窗口的周期传回数列。

检查十一个间隔，只需检查窗口末尾的 $45$ 项；因为 $44$ 是四的倍数，倒着读仍然得到相同的零点位置。所有可达窗口都不符合这个图案，而更长的串必以十一个间隔开头。检查十个间隔时只要看 $41$ 项，唯一匹配的是 $S_{2759}$：它止于第 $2820$ 项，起于第 $2780$ 项，内容是十组 $(0,1,2,2)$ 后接一个 $0$。这个窗口在循环里，因此每隔 $8946$ 项出现一个这样的起点。有限表能回答无限问题，不是因为表格很长，而是因为下一步一定还在表内。

## 从最后一个不同的位置开始数

设最小最终周期是四。用 $\mu=\mu_A(k)$ 表示最小的非负下标，使得所有 $n>\mu$ 都满足 $x_{n+4}=x_n$。设 $G=\lceil(k-1)/4\rceil$，把符合起点限制的 $G$ 间隔零点串的最早终点记为 $z$。之所以叫**捕获**，是因为这个串以零结尾，还给出了至少 $k$ 项是不是零的信息。终点的值加上这些信息，就足以确定往后的各项。起点 $s=z-4G$ 不必是周期尾部中的第一个零。

::: {#capture .remark mathesis="collected:finch-zero-runs:3:s2" title="定理 2：修正后的捕获偏移"}
设 $k\ge2$，且最小最终周期为四。$k=2$ 时 $z-\mu=9$；$k\ge3$ 时 $z-\mu=6$。后一种情形必有 $k\equiv2$ 或 $3\pmod4$。两类的起点分别为 $s=\mu-k+4$、$s=\mu-k+5$，而 $(x_\mu,x_{\mu+1},x_{\mu+2})$ 分别为 $(2,2,0)$、$(1,2,0)$。
:::

滞后量为二时，开头的例子从一开始就重复，所以 $\mu=0$。此时 $G=1$，第一对满足起点限制的零在第 $5$ 和第 $9$ 项。这就是为什么 Finch 原猜想的偏移量六在边界情形不成立，却适用于所有符合周期条件的较大滞后量。

对 $k\ge3$，把周期尾部向前延伸成四周期数列 $c$。一圈的增量之和模三为零，而增量为一的次数等于非零项数。最小周期为四，所以一圈恰有三个非零项。从唯一的零开始，四项是 $(0,1,a,2)$。唯一不动的一步必须回看那个零：$a=1$ 时这一步的偏移为二，$a=2$ 时为三。这就限制了 $k$ 模四的余数。

从第 $k$ 项起有连续 $k$ 个一，而周期块里最长只有两个或一个连续的一。因此两类分别有 $\mu\ge2k-3$、$\mu\ge2k-2$。记 $b_n=[x_n\ne0]$，令 $L=\mu+2-k$。当 $n\ge L$ 时，比较第 $n+k$ 步的增量：相邻两项都已经在共同的周期尾部，所以 $x$ 和 $c$ 在位置 $n$ 同为零或同为非零。在 $L-1$ 处两者的零指标必不同，否则会推出 $x_\mu=c_\mu$。这解释了为何零点图案可以比数值本身更早一致。

在 $\mu$ 处，两个数列的项不同但都非零。若差异落在周期块的第一个或最后一个非零处，错误的值会造成大小为二的增量，这是不可能的。因此差异落在中间的非零位置，得到定理 2 的三元组。再看第 $\mu+1$ 步，余二类有 $b_{L-1}=0$，余三类有 $b_{L-1}=1$。$\mu$ 之后的前两个零在 $\mu+2$ 和 $\mu+6$。捕获不能在 $\mu$ 或更早结束，否则会迫使从终点起就与 $c$ 一致。若希望在 $\mu+2$ 结束，余二类的起点是 $L-2$，但内部 $L-1$ 多出一个零；余三类的起点正是 $L-1$，却不是零。两种都失败。在 $\mu+6$ 结束时，起点分别为 $L+2$、$L+3$；$\mu$ 的下界保证起点合格，已一致的零指标保证整串成立。

::: {#neighborhood .remark mathesis="collected:finch-zero-runs:3:s3" title="推论 3：捕获起点之前的零点"}
在定理 2 的假设下，较大的余二类滞后量满足 $b_{s-4}=1$，余三类满足 $b_{s-5}=0$、$b_{s-1}=1$。当 $k=2$ 时，所提的邻域条件不成立：$s=5$，但 $b_{s-4}=b_1=0$。
:::

两类较大的滞后量都有 $x_{\mu-1}=1$：余二类中它紧跟在零后面且非零；余三类中它非零，且下一步是 $x_\mu=1$。于是进入 $x_\mu$ 的一步给出 $b_{\mu-k}$ 分别为 $1$、$0$，对应位置 $s-4$、$s-5$。余三类的 $s-1=L+2$ 处，根据已一致的零指标可知非零。$k=2$ 的例子只说明这个条件失效，本身并不否定 Finch 所提的整个等价关系。

## 证据与适用范围

锁定版本中的 Lean 证明利用滞后量 $61$ 缺少十一间隔图案，否定了上界总能达到的说法，但没有陈述十间隔的见证、全部起点或最小周期与前周期。另一条 Lean 证明用 $k=2$ 否定原捕获断言，而不是证明 $k\ge3$ 的一般修正或推论 3。后者有 Ma 和 Zhang 的书面证明；其他滞后量的有限例子并未判定所有最终周期为四的滞后量，也未解决 Finch 逐个列举的六个滞后量能否达到上界。共享贡献请求分别对应[滞后量 61 的精确结论](https://github.com/the-omega-institute/trureturing-requests/issues/367)、[有条件的捕获定理](https://github.com/the-omega-institute/trureturing-requests/issues/368)和[邻域条件](https://github.com/the-omega-institute/trureturing-requests/issues/369)。

原定义和问题见 [Finch 的 *Three Quadratic Recurrences Modulo 3* 第 4、6–7 节](https://arxiv.org/abs/2610.34300v1)。[Finch 2002 年的笔记第 0.2 节](https://www.mit.edu/~sfinch/seqmod3.pdf)记载了 B. Harder 对周期 $8946$ 的早期计算。[V. S. Miller 的记录](https://mathoverflow.net/questions/50678/finchs-sequence-over-mathbbf-3)保留了 R.
